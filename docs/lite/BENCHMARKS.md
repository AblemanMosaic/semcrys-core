# Benchmarks and accounting

Current claims must come from a rooted `account` or `corpus` result over named
artifacts. The four columns are:

1. worked `.crys` document bytes;
2. exact canonical shared `.leg` artifact bytes;
3. cold total (1 + 2);
4. XZ/LZMA preset-6 bytes over the unmodified source.

Warm accounting reads column 1. Cold accounting reads column 3. rc4 historical
figures compressed the legend counterfactually without materializing that
compressed artifact; rc5 supersedes those cold totals and break-even claims.

Assembly benefit and outer-codec benefit are measured separately. Phrase
assemblies can reduce logical event count while remaining neutral or negative
after LZMA captures the same recurrence. A result must not promote unit-count
reduction into a byte claim.

Legend ordering is likewise an independent CM2 choice. Frequency order normally
minimizes packed IDs; lexical order reduces ordering disclosure; first-appearance
order preserves introduction order. Disclosure is measured against the source,
not asserted from the profile name.

No universal compression-superiority claim is made.
