# S → CM1 → CM2 → IC → IR

`Specification` contains the total bounded phase space: byte unitization,
legend placement, occurrence projection, outer codec, moving-artifact
protection, and custody.

`CM1_FUNCTIONAL` retains only combinations that reconstruct exactly, root all
dependencies, refuse missing state, avoid partial publication, and require an
available established AEAD plus sufficient key material when a moving legend
becomes message-bearing.

`CM2_DESIRABLE` selects among functional combinations for one declared target:
simplicity, cold bytes, warm pre-shared bytes, reduced public recurrence, or
randomized public binding of message-bearing companions.

`INSTANCE_CONFIGURATION` pins the exact profile, legend roots, occurrence
mode, alias limit, codec, AEAD selection, and runtime-key presence without
recording the key.

`INSTANCE_REALIZATION` is the emitted `.crys`, any `.leg` artifacts, and the
receipt containing observed byte counts and roots.
