# Security Policy

SemCrys Core makes the bounded security claim recorded in
`RELEASE_CONTRACT.json`. It does not claim a complete protocol security proof,
endpoint security, password hardening, key escrow, or traffic-analysis
resistance.

Use GitHub private vulnerability reporting for suspected security issues when
it is enabled for the repository. Do not include secret keys, private data, or
exploit details in a public issue.

Reports should identify the affected version, profile, exact reproduction
steps, and whether the issue concerns confidentiality, integrity, replay,
resource bounds, or typed refusal.
